# 🌦️ Weather Notification App

This is a simple weather notification web application that fetches real-time weather data using the OpenWeatherMap API and displays it through browser notifications. The app is built using **HTML**, **CSS**, and **JavaScript** and is deployed using **Render**.

## 🔧 Features

- Enter any city name and get the current weather data.
- Displays weather info such as temperature, humidity, pressure, wind speed, and more.
- Sends system notifications with weather details.
- Graceful handling of invalid city input.
- Clean and responsive UI.

## 🧪 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- OpenWeatherMap API
- Render (for deployment)

## 🚀 How to Use

1. Open the deployed site.
2. Enter your city name in the input field.
3. Click the **Weather** button.
4. Allow notification permission in your browser.
5. Get a weather update directly via notification.
